# Contributing to SAS_MoCa

Thank you for considering contributing to _**SAS_MoCa**_! This document outlines the process.

## Types of Contributions

- **Bug reports**: Open an issue describing the problem with minimal reproducible code
- **Feature requests**: Describe the use case and expected behavior
- **Code contributions**: Submit pull requests with tests where applicable
- **Documentation improvements**: Typos, clarifications, example notebooks

## Pull Request Process

1. Fork the repository and create a branch from `main`
2. Update documentation for new features
3. Ensure existing tests pass
4. Thoroughly test or add tests for new functionality
5. Submit Pull Request with clear description of changes

## Questions?

If you are considering to contribute to _**SAS_MoCa**_, regardless of your background in Git/GitHub, please reach out via GitHub Discussions or email <enrico.semeraro@uni-graz.at>
