**SAS MoCa** is a Bayesian-constrained analysis software for small-angle scattering (SAS) data of complex membrane systems. It provides stochastic analysis tools for studying the structure of lipid membrane systems, including: 

- Large Unilamellar Vesicles (LUVs) 
- Protein-containing LUVs (pLUVs / proteoliposomes)
